Conversations

interface Conversations

Manage persisted conversations and their items. Deleting a conversation does not delete its items.

Default implementations throw UnsupportedOperationException so existing custom OpenAI implementations can remain source compatible without implementing this optional capability. Clients created by the SDK implement all operations.
